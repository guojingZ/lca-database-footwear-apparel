# ADR 001：完整保留上游，中文应用层独立维护

日期：2026-10-04。状态：已采纳（用户明确确认）。

## 问题

需要中文可理解、可开发的结构，同时保持原始资料可核查及可与上游更新比较。

## 决策

将上传快照按字节完整迁移到 `upstream/carbonfact/`，不在来源内翻译、替换结果或重排文件。中文说明、归一元数据、应用代码和测试在外层。来源基线用逐文件 SHA256 定位；上游版本和应用版本分别记录。

## 曾考虑的替代

- 在上游目录原位翻译和重构：会混淆原文与解释，增加内部链接与更新比较成本。
- 只保留整理后的表：会丢失方法学、许可、引用和建模证据。

## 理由与结果

用户优先完整保留快照；当前来源有单位差异、版本信息缺口和文档结果不同步，保留原文有助于核查。迁移清单及校验见 [source_manifest](../../data/source_manifest.json)与[升级指南](../覆盖升级指南.md)。

代价是根目录结构与上游不同，本地覆盖后必须清理旧位置；不能再用原仓库的重置工作区命令更新整个应用。源文件新增和元数据更新必须登记来源，而不直接修改现有快照。
