# 002：教学演示与产品工作台隔离

日期：2026-10-25。状态：采用。

## 背景

用户希望先理解概念、用已有 T 恤案例学习，再在独立模块走完从想法到落地的交互流程，同时不影响现有运行。

## 采用的选择

入口增加新人概念卡与案例导学；完整演示使用独立 /demo、独立脚本和浏览器存储键。演示通过参数生成教学模板，再调用原 Python 引擎。只有明确载入或导入，才把模型交给工作台。

共用学习内容和来源目录，分开用户操作状态。导出保持原 model 合同，增加演示参数、意见和步骤记录，原接口仍可重算。

## 理由与后果

避免演示重置、刷新和练习改变实际编辑任务，也避免网页实现第二套核算。模板与假设明确标注，缺项和边界复核不因学习完成而被批准。

学习进度仅存在本浏览器，不是账户同步或真实审批流。演示参数有限，自定义产品仍由工作台处理。真实 LLM 与企业知识更新需要后续独立实现。

验收与本机限制见 [验收报告](../验收报告.md)。
