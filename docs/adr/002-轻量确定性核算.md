# ADR 002：先实现可追溯的本地确定性核算

日期：2026-10-04。状态：已采纳（方案经用户确认并授权实施）。

## 决策

304 条记录使用 CSV/JSON 载体。标准库 Python 提供统一 Decimal 计算和本地 HTTP；网页只输入及展示。范围限于单主布质量链、原料配比、独立定量项目与互斥投入清单。缺项不归零，不自动生成不确定性和地区化结果。

## 替代与理由

数据库服务、复杂前端框架及云平台会增加本地操作负担，当前规模没有证明其必要。LLM 自动选择因子或完整 Brightway 重建需要更多治理与源数据，当前公开快照不足以直接保证。先让每次数量和结果可回溯，便于用户学习并接入自己的项目。

## 后果

本轮可展示和核算明确范围的部分结果；完整产品覆盖由用户业务数据与范围审阅补齐。底层科学准确性不是程序测试能证明的事实。接口和规则见 [开发接续](../开发接续.md)、[核算规则](../核算规则.md)。

未来扩展多部件、地区化或不确定性时，不能改变现有保存模型的含义，应升级 schema 并提供显式迁移。
