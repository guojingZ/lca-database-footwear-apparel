## 工序是什么

核心染色、后洗/漂洗、相关干燥与轧液等；排除前处理、防缩及紧缩。

| 项目 | 中文理解 |
|---|---|
| 功能单位 | 通常每 1 kg 对应产出；逐条以证据为准 |
| 主要投入 | 纤维/纱线/织物/成衣；电、热、水、染料、助剂及废水服务。 |
| 主要产出 | 1 kg 对应染色对象；废水、蒸发、损失材料与边界分别说明。 |
| 关键限制 | 中等色深代表工艺；染料存在背景代理。材料生产和损失材料去向需模型外处理。 |

## 可以学习和使用什么

38 条代表工艺；能学习工艺分类、投料公式、背景映射与代理，不能获得全部逐工序定量清单。详细解读见下文。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。

## 染色：投入产出能深挖到什么程度

优先证据：[染色方法学 PDF](../../upstream/carbonfact/datasets/dyeing/methodology/Dyeing_DB_Methodology.pdf)第 1、3–4、7–8、14–15 页；[化学品方法学](../../upstream/carbonfact/datasets/dyeing/methodology/Dyeing_Chemicals_Methodology.pdf)第 5–6 页。

| 项目 | 中文解释与来源深度 |
|---|---|
| 对象 | 纤维、纱线、织物、成衣分别有工艺，功能单位对应 1 kg 产出 |
| 电 | 方法学采用全球低压电力背景；部分工艺能量来源及逻辑可学习 |
| 热 | 定制燃料热源组合，涉及燃料能量与可用蒸汽口径、锅炉损失修正；不是任意企业热因子 |
| 染料 | 染料类别映射到代表生产路线，存在代理，非每个商用染料的实测清单 |
| 助剂 | 用 g/L、浴比、OWF、轧液率等推算；列功能与背景映射，不等于每条公开全部定量投料 |
| 水 | 工艺文献/供应商/浴比逻辑；路线用水跨度大，不把单次浴液量当作全过程总用水 |
| 废水 | 方法假设约 90% 工艺用水进废水、10% 蒸发；企业模型需确认适用性 |
| 损失材料 | 原料负担与损失处理在产品模型外层按所需量补充；与内嵌辅助废物区分 |

间歇染色一份浴液的助剂换算：`kg 助剂/kg 织物 = 浓度 c(g/L) × 浴液量 b(L/kg) / 1000`。假设 c=2、b=10 得 0.02；这两个数字仅解释公式，不是 Carbonfact 默认配方。

连续/冷轧堆的 OWF 与轧液率剂量口径不同，按专属方法理解。不能由染色总 GHG 减一个猜测电耗就当作“地区化替换”。

### 核心范围与组合

包含染色、后洗/漂洗、相关干燥与轧液；不含前处理、防缩和紧缩。加入独立烘干、后洗或能源清单时先判断原因子是否已经包含。工厂模板用聚酯退浆 → 分散常规喷射染 → PES 190°C 热定型，只表示结构与条件，没有宣称是所有涤纶染整工厂的真实流程。

### 公开模型的实际缺口

PDF 介绍的私有平台层级/JSON 不在本包中。所谓 Full LCI 附录主要列活动与分类；附录背景数据集名称也不等于完整交换数量。化学品 PDF 第 5 页说明部分气候影响值需查询 ecoinvent，不能从本快照完整复现。

牛仔靛蓝绳状染色使用蒽醌型还原染料背景代理。可以知晓这一建模选择，不能写成已掌握专属靛蓝生产模型。
