所列单项前处理或整理操作；专属方法学第 2 页为边界依据。

| 项目 | 中文理解 |
|---|---|

## 可以学习和使用什么

18 条含聚酯退浆、棉丝光、热定型、柔软、拒水、阻燃、涂层、机械整理等。不是任意材料都可以适用的 18 个空白模块。详细解读见下文。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。

原始类别说明：[上游 README](../../upstream/carbonfact/datasets/finishing/README.md)。全部数值见 [整理目录](../../data/processed/factors.csv)；具体记录的证据路径在 JSON 与页面详情中。

## 前处理与整理：把操作拆成有条件的模块

证据：[整理 PDF](../../upstream/carbonfact/datasets/finishing/methodology/Finishing_DB_Methodology.pdf)，重点第 2 页边界及各技术说明；[结果 CSV](../../upstream/carbonfact/datasets/finishing/impact-scores.csv)。

| 操作例 | 关键条件 | 使用提醒 |
|---|---|---|
| 连续退浆 | 聚酯 | 不能作为模板棉漂白的替代 |
| 丝光 | 连续棉工艺 | 不代表任意纤维的前处理 |
| 热定型 | 拉幅机，PES 190°C | GHG 原值 0.4593358479382707/kg |
| 热固着 | 棉 160°C | 与聚酯热定型分开匹配 |
| 柔软 | 浸轧烘干或喷射浸染 | 两种路径按实际技术选择 |
| 拒水 | C0 无氟或 C6 氟碳 | 化学体系分别建模 |
| 阻燃 | Pyrovatex N-P 或 Proban THPC | 配方/固着路径不同 |
| 防缩/紧缩/轧光/磨毛 | 机械技术 | 是否独立发生由真实流程决定 |

投入通常可归为织物、电/热及与操作相关的化学品、水、辅助服务；方法学解释参数与来源，不保证能取得所有完整逐条清单。输出与 GHG 按 1 kg 对应加工产出解释。

专属说明排除资本品，与通用方法学的表述不一致；不要把一张“所有加工均含资本品”的规则套在该类上。数值比为 1 也不等于证明企业没有任何材料变化。

染色已有干燥不等于工厂没有独立热定型；反过来，不能为了凑链条给染色再加一次同范围干燥。应记录真实操作、温度、停留、用途与包含范围。
