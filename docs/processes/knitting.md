## 工序是什么

纱线到针织物；按所选针织设备及条件。

| 项目 | 中文理解 |
|---|---|
| 功能单位 | 通常每 1 kg 对应产出；逐条以证据为准 |
| 主要投入 | 纱线；圆机、横机等电耗与相关间接/设备负担。 |
| 主要产出 | 1 kg 针织物；相应投入比用于反推纱线用量。 |
| 关键限制 | 圆机 dtex 记录分档；公开电耗公式不直接用于替换已发布影响值。 |

## 可以学习和使用什么

13 条包含圆机不同 dtex、横机、袜类、无缝与三维针织。圆机 lci.md 提供 E=0.01457+37.119/dtex 等参数化解释和区间；公式/表格需复核，v0.1 只使用已发布影响结果。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。

原始类别说明：[上游 README](../../upstream/carbonfact/datasets/knitting/README.md)。全部数值见 [整理目录](../../data/processed/factors.csv)；具体记录的证据路径在 JSON 与页面详情中。
