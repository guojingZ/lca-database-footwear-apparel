# 天然橡胶：中文工序卡

状态：来源已核对；中文内容是应用层解读。有效记录：4 条。

## 工序是什么

指定产地 STR 天然橡胶，摇篮到工厂门，含土地利用变化情景。

| 项目 | 中文理解 |
|---|---|
| 功能单位 | 通常每 1 kg 对应产出；逐条以证据为准 |
| 主要投入 | 指定产地天然橡胶生产，包括土地利用变化情景与相关生产系统。 |
| 主要产出 | 1 kg STR 天然橡胶；泰国、印尼、科特迪瓦、越南。 |
| 关键限制 | 缺 DQR 与投入产出字段；产地不同不直接代表企业供应链。 |

## 可以学习和使用什么

4 条按国家给出材料生产影响；没有 DQR 和投入字段。用于材料输入，需要供应地与模型假设一致；不是纺织加工因子。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。
