# 纺纱与长丝加工：中文工序卡

状态：来源已核对；中文内容是应用层解读。有效记录：159 条。

## 工序是什么

纤维进入，纱线或长丝产出；加工服务，不含纤维生产。

| 项目 | 中文理解 |
|---|---|
| 功能单位 | 通常每 1 kg 对应产出；逐条以证据为准 |
| 主要投入 | 纤维；电力；工艺相关辅助投入、设备与间接负担。 |
| 主要产出 | 纱线/长丝；加工损失按工艺记录及模型外规则核对。 |
| 关键限制 | 工艺、原料和纱支须对应；不能把 Cotton 纺纱当作棉种植因子。 |

## 可以学习和使用什么

原料×工艺×纱支记录最多，159 条。公开部分前景参数与工艺资料；原始纤维生产因子仍需外接。棉分机织/针织用精梳情景，不能把涤纶、粗梳羊毛和精梳羊毛互换。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。
