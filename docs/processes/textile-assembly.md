# 纺织品装配：中文工序卡

状态：来源已核对；中文内容是应用层解读。有效记录：15 条。

## 工序是什么

每 kg 装配产品的裁剪/缝制/整烫服务；专属说明含缝线、包装与裁剪损失。

| 项目 | 中文理解 |
|---|---|
| 功能单位 | 通常每 1 kg 对应产出；逐条以证据为准 |
| 主要投入 | 所需布料；裁剪、缝制、整烫电及间接能耗；缝线和包装等。 |
| 主要产出 | 1 kg 装配产品；裁剪损失存在专属/通用说明差异，需复核。 |
| 关键限制 | 与通用损耗说明存在差异，须复核外置处理与包装是否重复；不等于含布料生产的完整成衣因子。 |

## 可以学习和使用什么

15 个产品类型，不是 15 件实测衣服。通用装配值不含面料/纱线/纤维生产；包装和缝线不能再次完整相加。详细解读见下文。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。

原始类别说明：[上游 README](../../upstream/carbonfact/datasets/textile-assembly/README.md)。全部数值见 [整理目录](../../data/processed/factors.csv)；具体记录的证据路径在 JSON 与页面详情中。

## 装配：怎么从成衣反推面料

证据：[装配方法学说明](../../upstream/carbonfact/datasets/textile-assembly/methodology/README.md)、[PDF](../../upstream/carbonfact/datasets/textile-assembly/methodology/Textile_Assembly_DB_Methodology.pdf)、[CSV](../../upstream/carbonfact/datasets/textile-assembly/impact-scores.csv)。

功能单位为 1 kg 已装配产品。15 个产品类型代表通用裁剪、缝制与整烫等，不提供真实款式 BOM。

| 对象 | 如何理解 |
|---|---|
| 布料投入 | 按产品类型的投入比从成衣净质量反推；布料生产影响另接 |
| 能源 | 裁剪台、缝纫、整烫电力以及空调、压缩空气、照明等间接能耗 |
| 辅助材料 | 专属范围列缝纫线与包装；不能再完整重复增加 |
| 裁剪损失 | 专属范围列布料损失，通用说明另要求外置调整；处理范围须复核 |
| 排除 | 布料/纱线/纤维生产、分销、基础设施相关影响等按原文 |

长裤例：GHG `0.4241342917144142`，投入比 `1.1628`。若成衣 0.5 kg，则装配加工为 `0.5×0.4241342917144142`，所需装配前面料为 `0.5×1.1628=0.5814 kg`；更上游染色等应按自己的工序产出量接续反推。

这不意味着损失材料影响可以随意叠加。确认布料负担是否外置、损失处理是否已内嵌、包装范围与企业实际包装是否一致。本应用选择装配后要求填写 overlap_review，以保留这项边界检查。

T 恤模板列“其他配件/辅料”与“补充包装”的空位，是供盘点范围外新增项；若原装配因子已覆盖实际范围，明确说明排除或不再单列，不能把空位理解为一定要重复填值。
