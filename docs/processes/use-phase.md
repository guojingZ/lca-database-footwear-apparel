# 使用阶段与洗涤剂：中文工序卡

状态：来源已核对；中文内容是应用层解读。有效记录：15 条。

## 工序是什么

洗涤、干燥、熨烫或洗涤剂；功能单位逐条取 CSV。

| 项目 | 中文理解 |
|---|---|
| 功能单位 | 洗/干每 kg 织物；熨烫每分钟；洗涤剂每 kg |
| 主要投入 | 洗/干/熨烫活动或洗涤剂生产；次数、负载、温度、方式需自行定义。 |
| 主要产出 | 洗/干：kg 织物；熨烫：分钟；洗涤剂：kg。 |
| 关键限制 | 熨烫每分钟，洗涤剂每 kg，洗/干每 kg 织物；欧洲背景不能因 @GLO 解释成各国实测。 |

## 可以学习和使用什么

15 条，无 DQR/投入字段；欧洲背景的洗涤情景按原文解释。单次洗涤对象质量×次数是独立活动量；洗涤过程与另加洗涤剂需检查过程是否已经内含。

1. 在页面按本类别筛选，核对材料、设备、工艺参数和原始标识。
2. 按功能单位匹配活动量，确认包括/排除项。
3. 主布质量工序可按适用投入比反推；其他单位用独立定量入口。
4. 完整清单不足时使用已发布因子或明确的企业投入路径，不从总值猜配方。
