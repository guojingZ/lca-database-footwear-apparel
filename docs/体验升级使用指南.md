# v0.2.0：从新人入门到独立演示

日期：2026-10-25。性质：操作指南。适用：已覆盖 v0.2.0 并重新启动 Python 服务。

## 1. 怎样开始

在项目根目录运行 `python app.py`，浏览器打开 `http://127.0.0.1:8768`。默认先看“新人入门”。你也可以随时点击“产品与工序链”回到原有编辑器。

工作区顺序：新人入门 → T 恤贯穿案例 → 浏览因子 → 从 0 到 1 演示 → 自己的产品模型。“中文学习入口”继续保留文档与 12 类工序卡索引。

本轮默认案例仍为原 140 g 棉 T 恤，60% 有机棉、40% 再生棉，声明原料至成衣出厂。模板参数是教学设定；当前有原料、前处理等缺项，默认约 1.75876 kg CO₂e/件是已覆盖小计。

## 2. 新人入门怎样用

12 张背景卡先解释功能单位、活动量、影响因子与边界，再解释损耗、清单、缺项、版本、DQR 和比较。每张卡有 T 恤例子、常见误解和阅读依据。

展开“用 T 恤理解”，读懂后勾选已读。已读只记录学习进度，不代表因子获得专业批准；记录保存在本浏览器，换浏览器不会自动同步。

“跟着 T 恤学一遍”进入案例；“直接进入产品工作台”保留当前模型输入；“打开从 0 到 1 演示”进入独立页面。

## 3. T 恤贯穿案例怎样用

六个步骤可以顺序阅读，也可直接点：认识任务、读染色因子、反推数量、解释小计与缺项、做单变量练习、保存接续。

每一步提供当前操作与中文依据。染色按钮打开实际因子详情；数量表与分项来自同一 Python 引擎。

| 默认模板的量 | 数值 / 意义 |
|---|---|
| 成衣产出 | 0.14 kg |
| 装配前面料 | 0.160916 kg，来自 0.14 × 1.1494 |
| 染色产出 | 0.160916 kg，供后续整理与装配 |
| 染色 GHG 因子 | 4.001597083425285 kg CO₂e/kg 对应产出 |
| 染色贡献 | 约 0.643921 kg CO₂e |
| 起始纤维投入 | 约 0.218832 kg，基于模板统一质量链 |

下拉切换三个练习：

- 重量翻倍：默认 140 g → 280 g，小计约 3.51752。
- 配比 80/20：当前小计仍约 1.75876，因为原料因子尚缺，加工参数也未按材料分别改变。
- 装配损耗 20%：按投入定义，投入比 1.25；小计约 1.91089。只是数量传播练习，工序因子本身没有重新建模。

学习页面不改变产品编辑器。只有点“将当前案例载入产品工作台”，才会替换工作台当前输入；有个人输入时先保存。学习页与工作台所选练习是分开的，不要把两个区域的数值误认为同一份实时模型。

## 4. 数据与引用怎样看

“浏览因子”新增只看 T 恤案例记录的开关。默认模板实际选了 5 条公开加工记录，前处理缺因子，所以筛选得到 5 条。

详情先看：对象与工艺 → 功能单位 → 原始 GHG → 投入比 → 包含/排除 → 原始证据。中文工序卡帮助理解，CSV 保留原数值，README/PDF 给出单位或方法依据。

Markdown 链接进入新阅读页，显示标题、来源路径、内容和原始文本入口；表格、标题、列表与代码更易阅读。原始 PDF/CSV/JSON 仍可直接打开。Markdown 阅读器只呈现常用子集，不执行原文 HTML；源码请在本地编辑器查看。

多份方法学同时列出时，应优先看对应专属路线，例如圆机针织看 circular-knitting，环锭纺看 ring-spun。

## 5. 独立演示怎样走完

进入 `http://127.0.0.1:8768/demo`。演示不读取工作台当前模型，采用独立浏览器存储；不会写入公共来源、整理目录或个人模型文件。

| 步骤 | 你做什么 | 得到什么 |
|---|---|---|
| 1 想法与任务 | 写本次希望理解的问题 | 任务说明及固定教学边界 |
| 2 整理产品事实 | 填重量、两种棉的配比 | 白名单结构化参数，配比需合计 100% |
| 3 组合工序与选因子 | 看六工序，阅读染色候选，可采用或留空 | 代表工艺选择与教学阅读检查 |
| 4 运行与解释计算 | 点运行，可切换练习情景 | 质量链、贡献、小计与状态 |
| 5 缺项与资料需求 | 查看问题与下一步 | 采数和边界核查清单 |
| 6 复核与反馈 | 写来源/修正意见，演示采纳或退回 | 本次意见记录，公共知识不变 |
| 7 导出与接续 | 下载 JSON、中文报告或进度 | 可复算模型与交接材料 |

每一步可直接查看。“完成本步并继续”记录进度；阅读候选后才记录教学选择完成。改变上游输入会清除后续完成标记并使旧计算失效，防止展示旧结果。修正输入后可以重算继续。

情景中的“重量翻倍”以第 2 步当前输入为基线：若输入 200 g，采用重量为 400 g。“配比 80/20”使用指定配比。页面会显示实际采用重量。

演示计算仍为 partial 是正常现象。复核意见选择“演示采纳”只表示列入下一轮，不会使缺项消失，也不修改原始 GHG。

## 6. 演示保存、恢复和重置

本浏览器自动保存参数与学习进度。刷新会按当前参数重算，不直接拿旧结果冒充新结果。关闭浏览器前也可在第 7 步下载进度。

| 下载文件 | 用途 |
|---|---|
| `tshirt-demo-model.json` | 模型、结果、所选公开记录、学习参数与操作记录；可由原工作台加载 |
| `tshirt-demo-report.md` | 中文任务说明、情景、已覆盖贡献、缺项、复核意见与来源 |
| `tshirt-demo-progress.json` | 本演示进度备份，可在本页导入 |

“导入演示 JSON”恢复上述演示模型或进度，并按后台模板重算。自定义产品模型请用原工作台加载；演示只支持当前教学参数。若 JSON 中的 model 与演示参数不一致，拒绝静默覆盖。

目录版本不同会提示备份和重新核对，不自动替换因子。存储损坏时可重新开始；浏览器禁用存储时仍可学习并下载 JSON。重置只清除本演示进度，不动工作台。

导出的模型可用命令行重算：

```powershell
python tools/calculate.py local-data/tshirt-demo-model.json --output local-data/demo-recalculated.json
```

先将浏览器下载的 JSON 移入你建立的 `local-data/`。下载本身不会自动写到该目录。

## 7. 与真实企业任务的区别

演示展示模板与规则驱动的结构化过程，没有接入真实 LLM，也没有自动解析任意企业原文、批准因子或取得企业专属耗用数据。

真实任务仍需核查：重量和 BOM、实际加工路线、材料/设备/色深、数据地域与时间、投入产出依据、包含/排除项、原料与损失处理因子。

把演示的缺项转成实际资料需求，再用工作台补外部因子或企业投入清单。整项工序与同范围电热清单不能叠加。未知、零和明确排除继续分别处理。

## 8. 本次学习完成的标准

你能解释：因子表示什么？0.160916 kg 怎么得到？小计覆盖哪些工序？为什么材料配比改变可能暂时不改结果？缺项需要取得什么？别人怎样用同一模型重算？

业务学习先完成一件 T 恤，再整理一个标准染色模块；开发接续见 [开发接续](开发接续.md)，实施范围见 [本轮规划](../topics/v0.2.0体验升级.md)。
