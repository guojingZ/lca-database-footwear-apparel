# 字段、单位与原始数据

权威结构：[catalog.py](../carbonfact_app/catalog.py)、[原始 CSV](../upstream/carbonfact/datasets/)。整理目录：[factors.json](../data/processed/factors.json) / [factors.csv](../data/processed/factors.csv)。

## 一条整理记录

| 字段 | 含义 | 来源 / 未知处理 |
|---|---|---|
| `id` | 应用稳定标识，`cf-` 加原始描述符 SHA256 前 16 位 | 构建时验证唯一，不代替原始标识 |
| `descriptor` | 原始 Carbonfact 唯一描述符 | 原样保留 |
| `activity_zh` | 中文展示名 | `data/activity_names_zh.csv`，是翻译/解释，不修改工艺 |
| `activity_en` | 原始活动名称 | CSV `Activity`；原拼写错误也保留 |
| `category` / `category_zh` | 原文件类别和中文分类 | `data/categories.json`，12 类 |
| `unit` | 归一活动量单位：kg、m2、pair、min | 按专属 README 或逐条功能单位；单位依据在 `source` |
| `functional_unit_original` | CSV 原文功能单位 | 缺列时 null，不能假装原 CSV 有该列 |
| `input_ratio` | 原始投入字段值；适用工序中 kg 投入 / kg 产出 | 原始字符串，缺失 null。鞋类聚合投入不得套入单主布链 |
| `mass_chain_allowed` | 本应用是否允许用该条记录传递单主布质量 | 应用规则，不代表所有工艺适用性已获得上游认可 |
| `impacts` | 16 项影响原值 | 字符串保留 CSV 精度；后台用 Decimal 计算 |
| `dqr` | 四项数据质量评分 | 缺失 null；不生成综合分或不确定性 |
| `geography_tag` | 描述符 `@` 后标签 | 原样保留；鞋类电力情景另在 `#` 中，不能据此推断统一国家 |
| `data_year` | 逐条数据年份 | 本快照没有一致的独立年份来源，当前 null |
| `boundary` / `limitations` | 中文分类解释及已知限制 | 类别元数据；具体记录仍需核查原文 |
| `kind` | 原料/工序使用类型 | 应用辅助分类；洗涤剂作为原料投入有独立单位 |
| `source` | CSV、逻辑记录号、哈希、单位依据、方法学路径 | 可回到原文；记录号包含表头，不等同复杂引号 CSV 的物理行号 |
| `raw` | 原 CSV 全部字段 | 未归一的原始副本，保留差异和原精度 |

`catalog_digest` 覆盖来源、元数据、译名及归一结果。它改变后旧模型需重新匹配，不能用“同一个 id”就悄悄换入新值。`data/source_manifest.json` 记录 116 个来源文件哈希及原 ZIP 哈希。

## 16 项环境影响

以下“单位”是影响值分子，分母为**该条记录的功能单位**。专属工序说明优先于通用指标页的一律 `/kg` 表述。来源：[impact-indicators.md](../upstream/carbonfact/methodology/impact-indicators.md)。本轮产品计算只汇总 GHG，其余指标用于浏览与后续扩展。

| 代码 | 中文 | 影响值分子单位 |
|---|---|---|
| ACD | 酸化 | mol H⁺ eq |
| ETF | 淡水生态毒性 | CTUe |
| FRU | 化石资源使用 | MJ |
| FWE | 淡水富营养化 | kg P eq |
| GHG | 气候变化 | kg CO₂ eq |
| HTC | 人体毒性，致癌 | CTUh |
| HTN | 人体毒性，非致癌 | CTUh |
| IOR | 电离辐射 | kBq U-235 eq |
| LDU | 土地使用 | Pt |
| MRU | 矿物和金属资源使用 | kg Sb eq |
| OZD | 臭氧消耗 | kg CFC-11 eq |
| PCO | 光化学臭氧形成 | kg NMVOC eq |
| PMA | 颗粒物 | disease incidence（疾病发生量） |
| SWE | 海洋富营养化 | kg N eq |
| TRE | 陆地富营养化 | mol N eq |
| WTU | 水资源使用 | m³ world eq |

WTU 是表征后的水资源影响，不是企业工艺实际取水量。FRU 不是直接把企业燃料 MJ 原样相加的字段。上游说明采用 EF 3.1，GHG 使用 GWP100 并排除生物源碳；此处是记录来源的方法说明，本应用没有重新运行影响评价。

## DQR 与投入比不要混淆

| 原始字段 | 理解 |
|---|---|
| `P_dqr` | 精确性/可靠性 |
| `TiR_dqr` | 时间代表性 |
| `TeR_dqr` | 技术代表性 |
| `GR_dqr` | 地理代表性 |
| `Input_required_kg` / `Input required (kg)` | 两种拼写统一成 `input_ratio`；不是 IOR 环境指标 |

评分范围 1 到 5，较低表示较好。天然橡胶 4 条及使用阶段 15 条未提供 DQR；连同 PU 2 条，共 21 条未提供投入字段。没有评分不能填写 0。

## 怎样查看和维护

- Excel 打开中文 CSV 使用 UTF-8；整理 CSV 和中文映射已使用 BOM。编辑时不要让 Excel 将描述符或小数自动改写。
- 中文映射和类别说明是可维护输入；`data/processed/` 是构建输出。
- `python tools/data_workbench.py build` 构建；`validate` 同时检查原始来源、目录唯一性、影响值、DQR 与构建一致性。
- 因子数值不随译名解释改变。发现 README/PDF 与 CSV 不同，应登记差异并找证据，不自行猜测“正确值”。
