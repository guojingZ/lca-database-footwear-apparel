# 已知差异与公开深度

当前事实依据为用户上传快照。下面区分已验证差异和待验证问题；不直接改写上游。

## counts（已验证）

根 README 机织 19 条，CSV 17 条；非织造 2 条有效记录和 17 条全空记录。

处理：以有效 CSV 记录为目录；不修改上游文字。

证据：[README.md](../upstream/carbonfact/README.md)、[impact-scores.csv](../upstream/carbonfact/datasets/weaving/impact-scores.csv)、[impact-scores.csv](../upstream/carbonfact/datasets/non-woven/impact-scores.csv)。

处理：使用 CSV 原值；差异未经上游解释，不推测原因。

证据：[impact-scores.csv](../upstream/carbonfact/datasets/dyeing/impact-scores.csv)、[README.md](../upstream/carbonfact/datasets/dyeing/README.md)、[Dyeing_DB_Methodology.pdf](../upstream/carbonfact/datasets/dyeing/methodology/Dyeing_DB_Methodology.pdf)。

## loss-and-capital（已验证）

通用说明与具体说明对损耗/资本品边界表述有差异；整理专属 PDF 排除资本品。

处理：按具体工序证据，保留冲突；外置损失材料处理，不直接重复加工内嵌项。

证据：[overview.md](../upstream/carbonfact/methodology/overview.md)、[README.md](../upstream/carbonfact/README.md)、[Finishing_DB_Methodology.pdf](../upstream/carbonfact/datasets/finishing/methodology/Finishing_DB_Methodology.pdf)。

## units（已验证）

通用指标说明写所有记录每 kg，但运动鞋每双、PU 每 m²、熨烫每分钟。

处理：逐类/逐条取专属功能单位；不把通用分母套在全部记录上。

证据：[impact-indicators.md](../upstream/carbonfact/methodology/impact-indicators.md)、[README.md](../upstream/carbonfact/datasets/shoe-assembly/sneaker/README.md)、[README.md](../upstream/carbonfact/datasets/synthetic-pu-leather/README.md)、[impact-scores.csv](../upstream/carbonfact/datasets/use-phase/impact-scores.csv)。

处理：来源定位使用文件哈希；发布年不填作数据年。

证据：[CITATION.cff](../upstream/carbonfact/CITATION.cff)、[CHANGELOG.md](../upstream/carbonfact/CHANGELOG.md)。

## 装配包含项（已验证）

[装配专属说明](../upstream/carbonfact/datasets/textile-assembly/methodology/README.md)列缝纫线、包装和裁剪损失。与通用损耗处理说明的表达有差异。应用保留此冲突，并要求装配 overlap_review；不自动宣布外置损失处理一定不存在重复。

## 完整复现缺口（已验证的资料状态）

当前快照没有可直接完整重跑的全部原始 Brightway 模型、逐工序定量交换及背景数据。部分 Markdown 和 PDF 有参数、假设、公式与背景映射。详见 [染色卡](processes/dyeing.md)；不能仅由附录标题或数据集名称认定拥有完整底层清单。

## 哪些问题留待核查

原始部分数值与文档差异的原因、专属与通用损耗范围的精确衔接、针织公式/表格一致性、实际企业条件匹配均未被本轮程序测试证明。后续以原始证据或上游澄清更新，不猜测补齐。
