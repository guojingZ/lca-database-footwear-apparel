## 关键计算对照

测试夹具用独立合成数字，不能用于真实产品：最终 1 kg；后工序比 1.25、因子 3；前工序比 1.1、因子 2；材料因子 5；损失处理因子 1。前工序产出 1.25 kg，原料投入 1.375 kg，总损失 0.375 kg。手算：

`1×3 + 1.25×2 + 1.375×5 + 0.375×1 = 12.75 kg CO₂e`

程序与之相等；20% 按投入定义损耗等价于 1.25；未知投入比会停止上游数量传播，未知因子不填零；错误单位和重复因子阻止有效小计。整项工序与完整投入清单不能叠加。独立项目明确数量支持每双等单位。

默认真实来源结构模板：

| 模板 | 已覆盖小计 | 默认状态 |
|---|---|---|
| 140 g T 恤 | 约 1.75876 kg CO₂e/件 | partial；缺原料、前处理、其他项目与边界复核 |
| 100 kg 涤纶染整 | 约 665.49914 kg CO₂e/批次 | partial；边界待确认、损失材料处理因子缺失 |
| 企业染色投入清单 | null | partial；没有虚构量/因子，不给假零 |

模板只验证程序、链条与缺项行为；不是产品认证值，也不能与截图的完整模型直接比较。

## 尚未验证的环境行为

当前环境缺少可用的真实浏览器运行文件，尝试获取时未取得有效浏览器压缩包。界面检查因此采用模拟 DOM 与实际 HTTP，**没有完成真实浏览器布局、下载/选择文件对话框、小屏设备和键盘焦点的端到端验收**。JavaScript 与 HTTP 已检查，UI 测试脚本明确记录验证方式。

Windows 的 Python 启动命令、自动打开浏览器及用户本地 Git 升级尚待本机执行。页面保存所产生的 JSON 内容及加载重算已经验证，真实浏览器下载操作仍需本机确认。

底层 Brightway 全量复现、企业实际因子适配、复杂多部件/回收及不确定性不在本轮已验证范围。

## 在本机完成最后检查

1. 按 [升级指南](覆盖升级指南.md)盘点、备份、覆盖。
2. 运行 validate 与 Python 测试，再运行 `python app.py`。
3. 在页面修改重量、设基线、选择工序、查看来源；保存 JSON 后重新加载并核对小计及缺项。
4. 缩窄窗口确认表单和结果仍可操作；确认来源 PDF 能打开。

可选开发检查需 Node 20+；Windows 可指定 Python 命令：

```powershell
$env:CARBONFACT_TEST_PYTHON = "python"
node tests/ui_logic_smoke.cjs
```

这个脚本仍是逻辑检查，不替代真实浏览器验收。
