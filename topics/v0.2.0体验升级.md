# v0.2.0 体验升级规划

日期：2026-10-25。性质：本轮实施方案。用户已授权先规划后执行，并交付完整更新 ZIP；常规界面与实现选择按以下方案推进。

## 1. 问题与目标

v0.1.0 已能浏览 304 条记录、查看方法学并组合产品核算。入口首先展示编辑器，对第一次接触生命周期数据的人，概念、数据与操作之间仍缺少连续引导。上一轮的 140 g T 恤学习案例停留在独立文档中，尚未成为产品内可操作的学习路径。

本轮目标是让新人能依次回答：这是什么资料？一条因子表示什么？它怎样进入一件产品？结果从哪里来？缺项怎样继续处理？同时提供可重置、可保存、与现有核算工作台分开的完整演示。

## 2. 本轮交付范围

| 区域 | 用户看到什么 | 用户可以完成什么 |
|---|---|---|
| 新人入门 | 概念背景卡、项目分层、推荐路径、学习进度 | 先理解功能单位、活动量、因子、边界、损耗与缺项，再进入数据 |
| T 恤贯穿案例 | 步骤导航、真实模板、数量与贡献、三个单变量练习 | 跟读一条染色记录、重算重量/配比/损耗情景、进入原工作台继续 |
| 因子与资料 | 案例使用标记、中文工序卡入口、结构化来源说明、可阅读的 Markdown 页面 | 从记录回到依据；区分中文解读、公开原值与应用规则 |
| 独立全流程演示 | 单独 /demo 页面、任务输入、事实整理、候选复核、计算与诊断、导出 | 从一个教学任务走到模型、结果与下一步资料清单；可记录复核意见 |
| 现有工作台 | 原有产品、因子、学习资料入口 | 保持编辑、保存/加载、比较与外部因子操作可用 |

## 3. 新人入门的信息顺序

先给出“文件资料库 + 中文应用”的定位，再看概念卡。每张卡包含一句话解释、T 恤中的实例、常见误解和继续入口。采用项目已有资料中的概念，不把卡片写成完整标准教材。

卡片覆盖：数据与方法学、工序、功能单位、活动量、影响因子、系统边界、投入比与损耗、清单与整项结果、未知/零/排除、来源与版本、DQR、情景比较。

点击展开后可标记已读，进度仅保存在本浏览器。卡片不会成为业务审批条件。学习进度损坏或浏览器禁用存储时，页面仍能运行。

默认打开新人入门；熟悉用户可以直接选择“产品与工序链”。页面导航不重置现有模型。

## 4. 贯穿案例的学习设计

使用项目原有 examples/tshirt.json 与 templates.tshirt：140 g，60% 有机棉、40% 再生棉，六个工序。所有条件都标记为结构教学设定；默认结果为 partial，不能说完整产品足迹。

步骤：认识任务 → 读一条染色因子 → 从成衣反推数量 → 查看分项与缺项 → 做三个练习 → 保存并接续。

三个练习由同一个 Python 引擎产生结果：

- 重量翻倍：当前重量乘 2，已覆盖部分相应变化。
- 配比 80/20：材料因子缺失时当前加工小计不变，解释缺项的实际意义。
- 装配损耗 20%：按投入质量定义，投入比为 1.25，明确是教学假设。

案例说明、数量表和贡献从现有模板/目录/引擎生成，不在网页写第二套公式。只有明确点击“载入工作台”才替换工作台模型。

## 5. 独立演示的完整路径

| 步骤 | 输入与操作 | 可检查产物 |
|---|---|---|
| 1 想法与任务 | 填任务名，理解每件结果与原料至出厂边界 | 教学任务说明 |
| 2 事实整理 | 调整重量和两种棉的配比，区分事实与模板假设 | 结构化参数；错误配比清楚提示 |
| 3 工序与因子 | 查看六工序，阅读活性染色候选及不适用候选的排除理由 | 因子选择与复核记录；可保留缺因子 |
| 4 确定性计算 | 运行模板或单变量练习 | 后台产生的模型、质量链、贡献与状态 |
| 5 缺项与采数 | 查看缺因子、缺活动量、待复核范围 | 下一轮数据需求清单；不填假零 |
| 6 复核与反馈 | 记录新证据/修正意见，演示采纳或退回 | 仅本演示内的复核意见，不改公共知识或原始值 |
| 7 导出与接续 | 导出 JSON 模型证据包、中文 Markdown 报告 | 可在原工作台加载的模型及结果、公开来源记录、缺项与步骤记录 |

该流程使用模板与规则展示结构化过程，不接入 LLM 服务，不宣称自动完成真实企业资料解析或专业因子审批。人负责解释和复核，程序负责确定性执行。演示审阅记录不是认证。

## 6. 隔离和状态约定

演示独立 URL、独立脚本、独立浏览器存储键；不读取或改写工作台的 model/baseline。刷新可恢复本浏览器演示，用户可重置并导入演示 JSON。目录摘要不匹配时拒绝默默换用因子。

演示没有服务器文件写入；导出由用户下载。演示通过已有 Python 引擎计算。新 API 从明确白名单参数生成模板模型，原有 calculate/compare/export 接口继续使用原合同。

外部链接只在用户打开时访问；原始 CSV/JSON/PDF 保持可查看。Markdown 阅读器只访问限定的 docs/upstream/processed 文件，转义 HTML，不执行文件内容中的脚本。

## 7. 资料阅读与引用体验

记录保留中文名、英文名、descriptor、原始 GHG、功能单位、投入比、数据年、地域、边界、限制、DQR、源文件与逻辑记录号。展示 T 恤中使用该记录的工序，提供查看中文卡和原始依据的直接入口。

新增阅读页提供标题、来源路径、内容、原始文件入口。中文工序卡是解读，CSV 是已发布结果，PDF/README 是方法与单位依据；页面明确区分，不能把中文解释写成新的原始数值。

## 8. 实现范围

新增 learning.py 承载学习内容与教学模型组装；独立 demo.html/demo.js 与阅读页；在原 index.html/app.js 中增加新入口并接入学习数据。样式沿用轻量原生 CSS，改善导航、卡片、步骤与小屏展示。

更新版本号、README、PROJECT、WORKLOG、开发接续、体验说明及验收证据。保持引擎规则、来源快照、catalog_digest、原始 16 项值和三个旧模板不变。只生成新的应用发布清单，不重建来源哈希基线。

## 9. 实施顺序

1. 从上一交付包读取代码和规则，核对基线。
2. 完成本规划与当前状态回写。
3. 增加学习数据、教学场景、文档读取与 HTTP 接口。
4. 完成入门、案例及引用体验。
5. 完成独立演示、状态恢复、导入/导出与报告。
6. 验证旧功能、新功能、源数据保留、重复操作与错误恢复。
7. 更新文档、重建应用发布清单、打包并解压验证。

## 10. 验收标准

- 默认入门页有概念卡；从卡片能进入相关案例、记录或资料。
- T 恤默认小计与旧版本相同，保持 partial；三个练习与同一引擎的结果一致。
- 演示完成七步；参数变化后结果不滞留为旧值；错误输入可修正后继续。
- 演示刷新恢复、重置、JSON 往返与目录不匹配处理有验证；不会改工作台当前模型。
- 导出包可由原工作台重算；报告包含边界、教学标记、贡献、缺项、来源和后续动作。
- 文档路径受限，HTML/用户文字正确转义，阅读不会执行输入内容。
- 旧保存加载、比较、因子筛选、企业清单、数据校验继续通过。
- 所有 116 个上游来源与上一交付包逐字节一致，catalog_digest 不变。
- 实际浏览器/小屏如环境允许就执行；无法执行时明确列出方法和本机验收动作，不把模拟 DOM 当作真实浏览器验收。

## 11. 覆盖交付

交付完整 v0.2.0 ZIP，仍使用同名项目顶层目录。已有 v0.1.0 用户停止旧服务后复制包内内容到原根即可；本轮不设计复杂迁移，不触碰 .git、环境或个人模型。升级说明列出本轮是否有删除路径，避免用户猜测。

## 12. 后续边界

真实 LLM 接入、企业标准工序库、多部件质量网络、底层 Brightway 重算、外部因子自动批准及认证报告不纳入本轮。它们需要独立的数据与专业验证，不能由体验演示自动推导为已完成。
