# 后续迭代议题

性质：候选下一轮；本轮不自动扩大范围。

## 已确认方向

用户需要在中文语境中理解数据，并能用于自己的产品核算。结构采取完整上游 + 中文应用层。首轮入口和当前验收见 [PROJECT](../PROJECT.md)与[验收报告](../docs/验收报告.md)。

## 建议下一步

选择一款真实产品，先补齐结构模型的原料、前处理、配件和实际损耗；记录因子审阅和来源。由这个实例驱动标准工序映射与企业数据字段，而不是先追求通用自动化。

## 待确定的问题

| 问题 | 下一轮所需证据 |
|---|---|
| 标准工序库与因子映射 | 企业工艺定义、材料/设备条件、审阅依据 |
| 多部件/不同材料路径 | 每部件质量、连接点、质量增加/损失与分配规则 |
| 地区电热替换 | 可替换的明确前景用量、背景版本和工艺边界 |
| 企业投料清单 | 实测电热水化学品、废物、生产量及计量口径 |
| 底层模型重算 | 完整定量交换、背景数据访问和评价方法环境 |
| 不确定性 | 可证明的参数分布、相关性和传播方法；不能仅由 DQR 推出 |
| LLM/MCP 接入 | 候选筛选与人工审批责任、证据、保存/重算合同 |

染色靛蓝代理、针织公式一致性与通用/专属边界差异保持显式问题，不把它们写成已经解决的业务事实。
